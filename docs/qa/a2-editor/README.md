# A2. 공유 이미지 편집기 QA (2026-11-03)

로컬 서버(`python3 -m http.server`)와 Playwright로 iPhone(390×844)과 Android(412×915) 크기에서 10K 45:12 · 남성 · 1990년생 결과의 편집기를 열고 확인했어요.

## 확인한 것

| 항목 | 결과 |
|---|---|
| 템플릿 10종 × 형식 4종(9:16, 4:5, 1:1, 3:4) | 3:4에서 5종, 4:5 센터 모노가 깨짐 → 고침 (F1, F2) |
| 텍스트 추가, 글꼴 변경, 새로고침 뒤 글꼴 유지 | 이상 없음 |
| 사진 추가, 마스크 4종, 필터 12종, 90° 회전, 좌우 반전, 자르기(1:1·9:16·4:5), 배경 사진 | 이상 없음 (자르기 비율은 렌더 크기로 확인) |
| 스티커 4개 분류, 날씨 스티커 | 이상 없음. Open-Meteo는 이 환경에서 네트워크가 막혀 있어서, 응답을 가짜로 넣어 성공 경로를, 요청을 끊어 실패 안내 문구를 확인 |
| 잠금 | 옮기기·크기·회전에 더해 삭제, 복제, 배경 사진으로 바꾸기도 막아요 (F7) |
| 실행취소·다시실행 | 3건 고침 (F4, F5, F6) |
| 내 템플릿 저장·불러오기·삭제 | 썸네일 비율 고침 (F3) |
| 새로고침 뒤 상태 유지(사진, 배경 사진, 필터, 글꼴) | 이상 없음 (미리보기 픽셀 차이 평균 0.03) |
| PNG 저장 | 형식에 맞는 크기로 저장돼요 (4:5 → 1080×1350) |
| /log/ 카드 흐름 편집기(템플릿 13종, 형식 4종, 내 템플릿) | F4와 같은 문제만 있어서 같이 고침 |
| 패널 버튼 전부 누르기(텍스트·사진·스티커·기록·바탕·레이어) | 콘솔 에러 없음 |

콘솔 에러는 전 과정에서 0건이에요. 날씨 요청을 일부러 끊은 경우의 `net::ERR_FAILED`만 나왔어요.

## 찾은 문제

| # | 재현 | 기대 | 실제 | 처리 |
|---|---|---|---|---|
| F1 | 템플릿 → 3:4 → 폴라로이드 다꾸(센터 모노, 2분할, 3분할 콜라주, 메달 + 셀피도 같음) | 요소가 겹치지 않음 | 기록 숫자와 상위 %가 겹치고, 콜라주 기록 줄이 사진 칸 경계를 넘음 | 고침. 3:4 전용 스펙이 없어서 9:16 스펙을 1440 높이에 넣고 있었어요. 비율이 가까운 4:5 스펙을 쓰게 했어요 |
| F2 | 템플릿 → 4:5 → 센터 모노 | 라벨(페이스·상위·티어)이 1행 숫자 아래 | 라벨이 2행 숫자 위에 겹쳐 그려짐 | 고침. "상위" 라벨(30px)이 4:5 배율로 나누면 라벨 크기 기준을 넘어 값 행으로 분류되고, 그 아래 아래 라벨 행에 붙었어요. 값 행은 바로 아래 행이 라벨 행일 때만 붙게 했어요 |
| F3 | 1:1에서 내 템플릿 저장 → 4:5로 바꾸기 | 썸네일이 지금 형식 비율 | 9:16 칸에 세로로 늘어나 그려짐 | 고침. 지금 형식 높이로 그리고, 지금 형식으로 맞춰서 그려요 |
| F4 | 결과(또는 /log/ 카드)를 처음 열기 | 실행취소 비활성 | 실행취소가 켜져 있고, 눌러도 아무것도 안 바뀌고 계속 켜져 있음 | 고침. 첫 기록을 티어 색(acc)을 채우기 전에 찍어서, 되돌릴 때마다 같은 상태가 다시 쌓였어요 |
| F5 | 폴라로이드 다꾸 → 세로 매거진 → 실행취소 | 폴라로이드로 돌아감 | 한 번 더 눌러야 돌아감 | 고침. 템플릿을 놓은 뒤 화면 밖 요소를 당겨 넣는 자동 보정이 따로 기록됐어요. 보정 직전 상태가 이미 기록된 상태일 때만 그 기록에 합쳐요 |
| F6 | 템플릿 고르기 → 실행취소 | 목록 선택 표시도 이전 템플릿 | 선택 표시가 방금 고른 템플릿에 남음 | 고침. 내 템플릿은 어느 것인지 알 수 없어서 표시를 비워 둬요 |
| F7 | 요소 잠그기 → 삭제 또는 복제 | 잠긴 요소는 그대로 | 지워지거나 복제됨 | 고침. 미니 툴바, 길게 누름 메뉴, 휴지통, 여러 개 선택 삭제 모두 막고 "잠금을 먼저 풀어 주세요"라고 알려요 |
| F8 | 날씨 스티커 기온, 기록 카드 날씨 | 기온은 모두 °C | 템플릿 기본값은 `12°`, 불러온 값은 `11°C`, 직접 쓴 값은 쓴 그대로 | 고침. `12`, `12°`, `12도`, `12℃`를 `12°C`로 보여 줘요. 화씨(`54°F`)와 다른 숫자는 그대로 둬요. 스티커는 긴 기온이 틀에 닿지 않게 글자 크기를 줄여요 |
| F9 | 템플릿 → 4:5(또는 3:4) → 센터 모노 | 1행·2행 라벨 크기가 같음 | 1행 라벨이 조금 큼 | 고침. 4:5 데이터에서만 "상위" 라벨이 30px로 남아 있었어요. 9:16 대비 비율(24px)로 맞추니 9:16과 같은 규칙으로 정리돼요 |

## 고치지 않고 남긴 것

없어요. 처음에 남겼던 3건(잠금 삭제·복제, 날씨 단위, 4:5 센터 모노 라벨 크기)은 F7~F9로 고쳤어요.
