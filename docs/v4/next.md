# 다음

서버 없이 되는 곳까지만 본다.

운동이 끝나면 폰이 건강 앱 기록을 읽는다. 아이폰은 애플 건강, 안드로이드는 헬스 커넥트다. 그 운동에 들어 있는 항목은 빠짐없이 가져온다. 읽은 뒤 체감 피로 1~10을 한 번 묻고, 메모는 선택이다. [features/health-import.md](features/health-import.md)

이 컴퓨터에서는 건강 앱을 읽을 수 없다. Expo Go로는 건강 권한이 되지 않는다. 다음에 볼 화면은 건강 앱이 넣어 준 것과 같은 모양의 기록 하나를 넣고, 체감 피로와 선택 메모를 받는 화면이다. 실제 건강 앱 읽기는 개발 빌드가 있는 폰이 있을 때까지 비워 둔다.

로그인, 계정 저장, 운동 후 규칙 판단, 컨디션, 목표, 내일 훈련, 어제 추천 질문은 서버가 있는 다음이다. 개발 서버는 집 서피스 프로의 API다. 주소 이름은 `<개발용 API 주소>`로만 적는다. hoohaa.run은 고치지 않는다. [platforms.md](platforms.md)
