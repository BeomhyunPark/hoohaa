# 웹, 스토어, 워치

색인 [index.md](index.md). 기능은 플랫폼마다 다시 쓰지 않는다. 같은 기능 파일 하나로 iPhone, Android, 워치를 만든다.

## 말한 것

지금 만든 것은 웹앱이다. 이후 앱스토어, 구글 플레이, 워치 앱도 만든다. 워치는 애플워치와 웨어 OS를 따로 둔다. 한 워치 앱이 둘을 덮지는 않는다.

## 제안 — 세 겹

| 겹 | 하는 일 | 어디 |
|---|---|---|
| 핵심 | 티어·VDOT, Jev에 넣을 상태, 선택지, 문장 | 기능 파일. 플랫폼 이름 없음 |
| 서버 | 계정, 기록, Jev 호출. 키는 여기만 | 폰과 워치가 같이 씀 |
| 껍데기 | 화면, 건강 앱, 센서, 알림 | 웹, iPhone, Android, 애플워치, 웨어 OS |

## 결정 — 기술

폰은 React Native와 TypeScript다. iPhone과 Android 화면은 하나다. `src/engine/tier.js`와 `data.js`는 브라우저에 묶여 있지 않은 ES 모듈이라 폰에서 그대로 불러 쓴다. 계산을 Swift나 Kotlin으로 다시 쓰지 않는다.

스토어 빌드는 Expo Go가 아니다. 건강 앱 권한은 개발 빌드(prebuild)가 필요하다. Expo Go 안에서는 HealthKit과 헬스 커넥트가 되지 않는다.

화면 코드는 Xcode나 Android Studio에서 쓰지 않는다. 다만 아이폰 바이너리는 Xcode가 깔린 Mac에서만 만들어진다. 그 Mac은 내 컴퓨터일 수도 있고, EAS 같은 클라우드 빌드일 수도 있다. 인증서, HealthKit 권한, 스토어 업로드는 Apple 개발자 계정이 필요하다. 애플워치 SwiftUI는 Xcode 프로젝트가 된다. Android 빌드에는 Android SDK가 필요하다. Android Studio를 매일 열 필요는 없다.

서버는 TypeScript로 된 얇은 HTTP API다. 계정, 기록, Jev 호출만 한다. 키는 이 서버에만 둔다.

**결정.** 서버는 두 단계다. 개발과 검증은 집의 서피스 프로(Windows)에 올린다. 운영은 나중에 돈을 내고 쓰는 서버에 올린다. 스토어에 나가는 앱은 집 노트북을 바라보지 않는다.

서피스는 절전, 덮개 닫힘, 재부팅, 집 IP 변경으로 끊길 수 있다. 그건 개발·검증의 한계로 둔다. 운영 서버의 업체는 아직 정하지 않는다.

워치는 이 프레임워크 밖이다. 애플워치는 SwiftUI, 웨어 OS는 Kotlin이다. 화면은 작고, 판단은 폰이나 서버가 한 결과를 받는다.

웹은 지금 그대로다. 빌드 없는 정적 HTML이다. React로 바꾸지 않는다.

사진 편집기는 첫 폰 버전에 옮기지 않는다. 웹에 두고, [features/photo.md](features/photo.md)를 구현할 때 폰으로 옮길지 정한다. 편집기를 살릴 목적으로 웹뷰 껍데기를 고르지 않는다.

웹앱을 웹뷰로 감싸 스토어에 올리는 것은 v4가 아니다. 지금 웹은 계산기와 공유 편집기고, `9171085`에서 끝이다. 건강 저장소를 읽는 일과 워치 화면은 웹에 없다.

## 제안 — 순서

1. 웹은 고치지 않는다. hoohaa.run은 계산과 공유 카드로 남긴다.
2. 플랫폼이 갈리는 빈 칸부터 채운다. 건강 데이터를 저장소에서 읽으면 폰 앱이고, 공유 시트면 웹도 받을 수 있다. [features/health-import.md](features/health-import.md)를 본다.
3. 폰을 먼저 만든다. iPhone과 Android는 기능 파일을 같이 쓰고, 건강 앱 연결만 껍데기가 따로다. 스토어 제출, 개발자 계정, 패키지 이름은 그 기능이 동작한 뒤의 일이다.
4. 워치는 나중에 만든다. 오늘 판단의 결과나, 달리는 중 페이스와 심박을 보여 주는 껍데기다. Jev는 워치가 직접 부르지 않는다. 폰이나 서버가 부른 결과를 받는다. [features/live-pace.md](features/live-pace.md)가 후순위인 이유와 같다.

## 빈 칸

개발·검증용 HTTPS 주소. 운영 서버를 어느 업체에 둘지. 새 앱과 hoohaa.run이 같은 제품인지. 워치에 올릴 첫 화면이 오늘의 판단인지, 달리는 중 페이스인지.
