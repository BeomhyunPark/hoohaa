# 올리지 않은 제안

기능 파일로 만들지 않은 후보다. 개발 범위가 아니다. 다시 올리려면 이유와 함께 그 기능 파일을 새로 만들고, 색인에 한 줄을 더한다.

| 후보 | 올리지 않은 이유 |
|---|---|
| 캡처·완주증으로 기록 인증 | 스크린샷은 만들기 쉽고, noul 한 건은 보장이 아니다. 틀린 "인증됨"이 없는 것보다 나쁘다. |
| 사진 속 얼굴 위치로 카드 자동 배치 | 편집기 "인물 뒤로"가 이미 기기 안에서 MediaPipe로 한다. 사진을 Jev에 보내지 않는다. |
| 사진 종류로 템플릿 고르기, 배경 품질 score | 이미지 입력은 실험 기능이다. 편집기는 이미 템플릿을 사람이 고른다. |
| 대회 전 테이퍼, 부상 위험 noul | 남은 날과 주간 거리는 코드가 비교한다. Jev 자리가 아니다. |
| 티어 변화 타임라인, 시즌 배지 | "잡다한 것"의 목록이 아직 없다. |
| 경로를 카드에 새로 만들기 | 스티커 `data_course`가 이미 있다. [features/photo.md](features/photo.md)에 적었다. |
