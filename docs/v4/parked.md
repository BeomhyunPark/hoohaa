# 올리지 않은 제안

기능 문서로 만들지 않은 후보다. 지금 만들 범위가 아니다. 다시 넣으려면 이유를 적고 기능 문서를 새로 만든 다음, [index.md](index.md)에 한 줄을 더한다.

| 후보 | 올리지 않은 이유 |
|---|---|
| 캡처·완주증으로 기록 인증 | 스크린샷은 만들기 쉽고, 자동 판단 한 건은 보장이 아니다. 틀린 "인증됨"이 없는 것보다 나쁘다. |
| 사진 속 얼굴 위치로 카드 자동 배치 | 편집기 "인물 뒤로"가 이미 기기 안에서 MediaPipe로 한다. 사진을 서버로 보내지 않는다. |
| 사진 종류로 템플릿 고르기, 배경 품질 score | 이미지 입력은 실험 기능이다. 편집기는 이미 템플릿을 사람이 고른다. |
| 대회 전 테이퍼, 부상 위험 자동 판단 | 남은 날과 주간 거리는 코드가 비교한다. 테이퍼는 [rules.md](rules.md)의 내일 훈련 시기 규칙에 있다. |
| 티어 변화 타임라인, 시즌 배지 | "잡다한 것"의 목록이 아직 없다. |
| 코스 스티커를 새로 그리기 | 스티커 `data_course`가 이미 있다. 거리와 코스 이름을 적어 붙이는 장식이고, 뛴 경로는 아니다. 뛴 경로는 [features/photo.md](features/photo.md)에서 새로 정한다. |
