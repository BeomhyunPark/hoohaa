# 문장

목록은 [../index.md](../index.md)다. Jev를 호출하지 않는다.

## 하는 일

**결정.** 화면에 나오는 말은 우리가 쓴다. 선택지 이름, 코칭, 내일 훈련 메뉴, 보류일 때 보여 주는 말이 여기 들어간다.

기능 문서는 선택지만 정한다. 문장은 이 문서에서 종류별로 둔다.

## 말투

**말한 것.** 지금 웹앱의 화면 말은 해요체다. 새 문장도 그 말투를 기준으로 둔다. 정하기 전에는 다른 말투로 쓰지 않는다.

화면에 보이는 문장은 한국어다. Jev에 넣는 글은 영어다. [../engine.md](../engine.md)를 본다.

## 운동이 끝난 뒤

건강 앱에서 기록을 읽고, 체감 피로를 한 번 물은 뒤 컨디션, 목표, 내일 훈련을 한 화면에서 보여 준다.

중괄호는 코드가 넣는 숫자다.

### 컨디션

| 자리 | 문장 |
|---|---|
| 그대로 훈련 | 평소 훈련을 이어가도 돼요. |
| 강도 낮추기 | 다음 훈련은 강도를 낮춰요. |
| 휴식 | 다음 훈련은 쉬어요. |
| 판단 보류 | 오늘은 판단하지 않아요. |

**결정.** 컨디션 문장 옆에 "의학적인 진단은 아니에요."를 둔다.

휴식 또는 강도 낮추기이면 해당 문장을 먼저 보여 주고, 내일 훈련을 뒤에 보여 준다. 그대로 훈련이거나 컨디션 판단을 할 수 없는 경우에는 내일 훈련을 그대로 보여 준다. [tomorrow.md](tomorrow.md)

판단 보류는 충분한 기록이 쌓이지 않은 경우에 쓴다. 구체적인 기준 숫자는 실제 기록을 확인한 뒤 정한다. 기준이 정해지기 전에는 컨디션 판단을 하지 않고 이력만 남긴다. [condition.md](condition.md)

### 목표

대회 목표가 설정된 경우에만 보여 준다. 받는 항목은 [goal.md](goal.md)에 정했다.

| 자리 | 문장 |
|---|---|
| 달성 유력 | 지금 흐름이면 목표 기록에 닿을 가능성이 커요. |
| 가능 | 지금 흐름이면 목표 기록에 닿을 수 있어요. |
| 어려움 | 지금 흐름과 목표 기록 사이가 아직 커요. |

### 내일 훈련

| 자리 | 문장 |
|---|---|
| E | 대화가 되는 속도예요. km당 {E}로 달려요. |
| M | 긴 조깅 중간에 20~40분을 km당 {M}로 달려요. 앞뒤는 km당 {E}예요. |
| T | km당 {T}로 1km × {횟수}를 하고, 사이에는 1분 조깅해요. |
| I | km당 {I}로 {거리} × {횟수}를 하고, 사이에는 2~3분 조깅해요. |
| R | {거리} × {횟수}를 하고, 사이에는 숨이 돌아올 때까지 걷거나 천천히 조깅해요. |
