# 문장

목록은 [../index.md](../index.md)다. 판단 결과의 템플릿 문장은 [../rules.md](../rules.md)에 있다.

## 하는 일

**결정.** 화면에 나오는 말은 우리가 쓴다. 선택지 이름, 코칭, 내일 훈련 메뉴, 보류일 때 보여 주는 말이 여기 들어간다.

기능 문서는 선택지만 정한다. 문장은 이 문서에서 종류별로 둔다.

## 말투

**말한 것.** 지금 웹앱의 화면 말은 해요체다. 새 문장도 그 말투를 기준으로 둔다. 정하기 전에는 다른 말투로 쓰지 않는다.

화면에 보이는 문장은 한국어다. 규칙 템플릿도 한국어 해요체다. [../rules.md](../rules.md)를 본다.

## 운동이 끝난 뒤

건강 앱에서 기록을 읽고, 체감 피로를 한 번 물은 뒤 컨디션, 목표, 내일 훈련을 한 화면에서 보여 준다.

중괄호는 코드가 넣는 숫자다.

### 기록과 체감 피로

**결정.** 건강 앱에서 읽은 기록을 짧게 보여 주고, 체감 피로와 메모를 받는 자리의 문장이다. 받는 항목은 [health-import.md](health-import.md)에 정했다. 폰 앱 코드는 [mobile/src/copy/after-run.ts](../../../mobile/src/copy/after-run.ts)이고, 테스트가 이 표와 코드의 문장이 같은지 본다.

이 자리에는 컨디션, 목표, 내일 훈련, 통증 판단 문장을 두지 않는다. 메모의 자리 표시는 사용자가 적을 말의 예시이고 진단이 아니다.

| 자리 | 문장 |
|---|---|
| 기록을 읽는 중 | 기록을 읽고 있어요. |
| 건강 앱에 운동이 없을 때 | 가져온 운동 기록이 없어요. |
| 기록을 읽지 못했을 때 | 기록을 읽지 못했어요. |
| 다시 읽는 버튼 | 다시 읽기 |
| 기록 제목 | 운동 기록 |
| 기록 항목 | 날짜 |
| 기록 항목 | 거리 |
| 기록 항목 | 시간 |
| 기록 항목 | 평균 페이스 |
| 기록 항목 | 평균 심박 |
| 체감 피로 제목 | 체감 피로 |
| 체감 피로 질문 | 이번 달리기는 얼마나 힘들었어요? |
| 1과 10의 뜻 | 1은 아주 편했을 때, 10은 온 힘을 다했을 때예요. |
| 메모 제목 | 메모 (선택) |
| 메모 자리 표시 | 예: 왼쪽 무릎이 조금 아파요 |
| 저장 버튼 | 저장 |
| 체감 피로를 고르지 않았을 때 | 체감 피로를 골라야 저장할 수 있어요. |
| 저장하지 못했을 때 | 저장하지 못했어요. 다시 눌러 주세요. |
| 저장한 뒤 | 저장했어요 |
| 저장한 뒤 메모 칸 이름 | 메모 |
| 저장한 값을 고치는 버튼 | 수정 |
| 고치기를 그만두는 버튼 | 취소 |

기록 항목은 값이 있을 때만 보여 준다. 값은 숫자와 단위다(예: 5.01 km, 28:32, 5:42/km, 156 bpm).

화면에는 보이지 않고 화면 낭독기가 읽는 이름이다. 중괄호는 코드가 넣는 숫자다.

| 자리 | 문장 |
|---|---|
| 체감 피로 버튼 묶음 | 체감 피로, 1부터 10까지 |
| 버튼 1 뒤에 붙는 뜻 | 아주 편했어요 |
| 버튼 10 뒤에 붙는 뜻 | 온 힘을 다했어요 |

버튼 이름은 "체감 피로 {숫자}"다. 양 끝은 뜻을 붙여 "체감 피로 1, 아주 편했어요", "체감 피로 10, 온 힘을 다했어요"로 읽는다. 가운데는 "체감 피로 5"처럼 숫자만 읽는다.

### 컨디션

| 자리 | 문장 |
|---|---|
| 그대로 훈련 | 평소 훈련을 이어가도 돼요. |
| 강도 낮추기 | 다음 훈련은 강도를 낮춰요. |
| 휴식 | 다음 훈련은 쉬어요. |
| 판단 보류 | 오늘은 판단하지 않아요. |

**결정.** 컨디션 문장 옆에 "의학적인 진단은 아니에요."를 둔다.

휴식 또는 강도 낮추기이면 해당 문장을 먼저 보여 주고, 내일 훈련을 뒤에 보여 준다. 그대로 훈련이거나 컨디션 판단을 할 수 없는 경우에는 내일 훈련을 그대로 보여 준다. [tomorrow.md](tomorrow.md)

판단 보류는 충분한 기록이 쌓이지 않은 경우에 쓴다. 구체적인 기준 숫자는 실제 기록을 확인한 뒤 정한다. 기준이 정해지기 전에는 컨디션 판단을 하지 않고 이력만 남긴다. [condition.md](condition.md)

### 목표

대회 목표가 설정된 경우에만 보여 준다. 받는 항목은 [goal.md](goal.md)에 정했다.

| 자리 | 문장 |
|---|---|
| 달성 유력 | 지금 흐름이면 목표 기록에 닿을 가능성이 커요. |
| 가능 | 지금 흐름이면 목표 기록에 닿을 수 있어요. |
| 어려움 | 지금 흐름과 목표 기록 사이가 아직 커요. |

### 내일 훈련

| 자리 | 문장 |
|---|---|
| E | 대화가 되는 속도예요. km당 {E}로 달려요. |
| M | 긴 조깅 중간에 20~40분을 km당 {M}로 달려요. 앞뒤는 km당 {E}예요. |
| T | km당 {T}로 1km × {횟수}를 하고, 사이에는 1분 조깅해요. |
| I | km당 {I}로 {거리} × {횟수}를 하고, 사이에는 2~3분 조깅해요. |
| R | {거리} × {횟수}를 하고, 사이에는 숨이 돌아올 때까지 걷거나 천천히 조깅해요. |
