# 문장

색인 [../index.md](../index.md). Jev를 부르지 않는다.

## 하는 일

**결정.** 화면에 나오는 말은 우리가 쓴다. 선택지 이름, 코칭, 내일 훈련 메뉴, 보류일 때 보여 주는 말이 여기 들어간다.

기능 파일은 어떤 선택지인지만 정한다. 문장 초안은 이 파일에만 쌓는다. 아직 초안이 없다.

## 말투

**말한 것.** 지금 웹앱의 화면 말은 해요체다. 새 문장도 그 말투를 기준으로 둔다. 정하기 전에는 다른 말투로 쓰지 않는다.

Jev에 보내는 언어는 화면 말과 따로다. [../engine.md](../engine.md)를 본다.
