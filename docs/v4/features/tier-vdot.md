# 티어와 VDOT

색인 [../index.md](../index.md). Jev를 부르지 않는다.

## 하는 일

목표가 있으면 목표 기록의 VDOT도 코드가 계산한다. [goal.md](goal.md)의 상태는 그 숫자를 받는다. 훈련 페이스 E·M·T·I·R도 여기서 나온다. [tomorrow.md](tomorrow.md)가 문장에 끼운다.

## 하지 않는 일

## 지금 hoohaa
