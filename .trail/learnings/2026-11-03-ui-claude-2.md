## Decided
- 앱 UI/UX 전면 손질은 피그마 시안을 먼저 만들고, 사용자가 확정한 뒤에 코드에 옮긴다(사용자 요청).
- 색상 톤, 로고, 결과 화면의 티어 카드 디자인은 바꾸지 않는다(사용자 확정). 바꾸는 건 화면 구조와 강약뿐이다.
- 사용자가 꼽은 불만: 정보가 빽빽하고 평평함, 입력 폼이 딱딱함. 시안 방향: 화면마다 주인공 하나(입력=큰 기록 숫자, 결과=티어 카드), 종목·성별은 세그먼트 트랙, 결과는 3칸 요약 + 탭(티어표/예상 기록/훈련 페이스) + 하단 고정 공유 버튼.
- 시안 파일은 사용자 피그마의 BH 팀(드래프트)에 둔다(두 팀 BH, hyunee 중 사용자가 선택).

## Tried and ruled out
- 첫 시안에서 티어 카드를 단순화해 다시 그렸다(칩·워터마크·금속 질감 빠짐, 글꼴 변경). 사용자가 카드는 그대로 두라고 해서, 실제 앱에서 렌더된 값(색·Kode Mono·칩 SVG·워터마크)을 그대로 옮긴 컴포넌트로 바꿨다.
- 현재 화면 캡처를 피그마에 올리려 했으나 클라우드 세션 네트워크 정책이 mcp.figma.com 업로드를 403으로 막았다. 비교는 저장소의 기존 스크린샷으로 한다.

## Watch out
- 기록 입력은 "숫자만, 뒤에서 2자리씩" 규칙 그대로다. 코드로 옮길 때 입력 규칙을 바꾸지 않는다.
- 피그마에는 Pretendard가 없어 Noto Sans KR로 대신 그렸다. 카드 노이즈 질감도 피그마에서는 생략했다. 실제 앱 글꼴·질감은 기존 그대로다.
- 새 색 토큰은 bg/sunken(#0B1119) 하나만 추가했다.
